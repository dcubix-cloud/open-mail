# Open Mail website

This is the landing page for Open Mail. It's a small static site, and like the rest of the project it's open source.

## Help us make it better

Design contributions are very welcome. If you have an eye for layout, illustration, motion or words, we'd love your help, from a small fix to a whole new section. For example:

- a cleaner or bolder layout
- illustrations in the hand-drawn style of the hero
- smoother animations in the demos
- clearer, friendlier copy
- better on phones and tablets
- more accessible

You can open an issue with a sketch or screenshot, or send a pull request. Rough ideas are fine; we'll shape them together.

## Try it locally

You'll need [Node.js](https://nodejs.org).

```sh
npm install
npm run dev
```

## A few things to keep

- **Show the real app.** The demos are the app's own screens, so they only show what Open Mail actually does.
- **No outside requests.** No trackers, fonts or scripts from other sites.
- **Light and simple.** A light theme and short, plain words.

## Building it

`npm run build` puts the finished site in `dist/`, ready for any static host.
